## 🤖 Overview

Weesper Transcribe converts audio and video files to text using local Whisper models, supporting 90+ languages with speaker diarisation and subtitle export.

Whether you're a newcomer or a veteran, Weesper Transcribe provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Offline First** | All transcription runs locally with no data sent to servers |
| **Speaker Labels** | Diarisation separates and labels different speakers automatically |
| **Subtitle Export** | Export transcripts as SRT, VTT, or plain text files |
| **Multi-Format** | Accepts MP3, MP4, WAV, M4A, and most common audio/video formats |
